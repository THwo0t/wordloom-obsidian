写入前保存完整备份，写入后核对 SHA-256、单词总表、既有详解与保护边界；任何检查失败都会停止写入或自动恢复。

Cambridge 官方 API（可选）

普通个人网络可直接读取网页；如果遇到安全验证，或准备长期分发，请申请 Cambridge Dictionary API Access Key。配置后会优先使用官方英汉简体词典 XML 接口。

Key 不会交给页面或 DeepSeek。
